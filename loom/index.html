FAQ
Questions, answered.
Everything you need to know before you weave your first site. Still curious? Ask us.

        

          
What can the AI agents do, and what can’t they?
They build sites and pages from a description, set accessible palettes and fonts, write copy, draw logos and illustrations, add motion, run accessibility, QA, security and SEO checks, write marketing plans and prepare storefronts and launches. They never buy domains, take payments, order stock or spend on ads for you. Those arrive as checklists you approve and do yourself.

          
Does Loom AI need an API key?
No. Every agent has a built-in version that runs in your browser. Connect Claude (set ANTHROPIC_API_KEY on the Loom server) and the same agents get much more creative. Your key stays on the server and is never sent to the browser.

          
Do I need to know how to code?
No. Loom is fully visual: add elements, style them in the panel and publish. If you do know HTML and CSS, the code Loom writes will feel familiar and clean.

          
How is Loom different from a page builder?
Loom works the way professional designers do: reusable classes, a real box model, flex and grid, and a responsive cascade — instead of fixed blocks you can’t reshape.

          
Where can I host the sites I publish?
Anywhere that serves static files — GitHub Pages, Netlify, Vercel, Cloudflare Pages or your own server. Publishing writes plain HTML and CSS into a folder.

          
Can I use the templates commercially?
Yes. Use and modify any template on as many of your own sites as you like, including client work. Just don’t resell the templates themselves.

          
What happens to my data?
Your projects are yours. We collect only what Loom needs, never sell data and don’t use tracking cookies. You can export or delete everything from your account. See the Privacy Policy.

          
Is Loom accessible?
We care a lot about this. Loom encourages semantic tags, warns about missing alt text, and the editor is keyboard-navigable. Published sites are as accessible as the content you create.
